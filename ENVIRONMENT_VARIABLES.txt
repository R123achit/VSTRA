# ============================================
# DEPLOYMENT INSTRUCTIONS
# ============================================

1. Go to: https://vercel.com/new
2. Import your GitHub repository (R123achit/VSTRA)
3. Before deploying, click "Environment Variables"
4. Add each variable above (one by one)
5. For each variable:
   - Name: Copy the variable name (e.g., MONGODB_URI)
   - Value: Copy the value after the = sign
   - Environment: Select "Production", "Preview", and "Development"
6. Click "Deploy"

# ============================================
# POST-DEPLOYMENT STEPS
# ============================================

After first deployment:

1. Copy your Vercel URL (e.g., vstra-abc123.vercel.app)

2. Update NEXTAUTH_URL:
   - Go to Settings → Environment Variables
   - Find NEXTAUTH_URL
   - Update value to: https://vstra-abc123.vercel.app
   - Click "Save"
   - Redeploy: Deployments → Latest → "Redeploy"

3. Test your deployment:
   - Visit your Vercel URL
   - Try registering/logging in
   - Place a test order
   - Check if email arrives

4. Configure MongoDB Atlas:
   - Go to MongoDB Atlas Dashboard
   - Network Access → Add IP Address
   - Click "Allow Access from Anywhere" (0.0.0.0/0)
   - Confirm

# ============================================
# TROUBLESHOOTING
# ============================================

If deployment fails:

1. Check build logs in Vercel dashboard
2. Verify all required variables are set
3. Ensure MongoDB allows connections from anywhere
4. Test locally: npm run build
5. Check for syntax errors in environment variables

Common Issues:

- "Module not found": Run npm install and commit
- "MongoDB connection failed": Check network access in Atlas
- "Email not sending": Verify Gmail App Password
- "Payment failed": Check Razorpay keys and webhook setup
